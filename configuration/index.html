    설정 · 시크릿 정책¶

    Vendor-Portal-V2-Backend(Spring Boot 3.5 / Java 21)의 설정 구조를 정리한다. 모든 실 설정 파일은 git에서 제외되고 *.example 템플릿만 커밋되며, 하드코딩되던 비밀값은 @Value로 외부화되어 있다.

    설정 파일 레이아웃¶

    설정은 src/main/resources/ 아래의 YAML 다섯 종(공통 + 프로파일별)으로 구성된다. 실파일은 비커밋, .example만 커밋된다.

    파일 역할 커밋 여부
    application.yaml 공통(base) 설정 — 서버/Spring/Security/MyBatis/WebPush 등 제외(gitignore)
    application-default.yaml 로컬 default 프로파일 — 포트 9041, DataSource 제외
    application-dev.yaml 개발(dev) 프로파일 — DataSource, Redis 제외
    application-prod.yaml 운영(prod) 프로파일 — DataSource, Redis 제외
    application-azure.yaml Azure(ACA) 프로파일 — 시크릿은 컨테이너 env(KV secretRef)로 주입, 파일엔 정적 설정만 제외
    application*.yaml.example 위 다섯 파일의 placeholder 템플릿 커밋

    gitignore 규칙

    .gitignore에 src/main/resources/application*.yaml 한 줄로 모든 실 YAML이 제외된다(.gitignore:22). .example 접미는 패턴에 안 걸리므로 커밋된다. 신규 프로파일/시크릿 추가 시 실값을 절대 커밋하지 말 것.

    부트스트랩 (.example → 실파일)¶

    클론 또는 신규 환경에서는 .example을 실파일로 복사한 뒤 __PLACEHOLDER__ 토큰을 실값으로 치환해야 기동된다.

    cd src/main/resources
for f in application application-default application-dev application-prod application-azure; do
  cp "$f.yaml.example" "$f.yaml"
done
# 이후 각 *.yaml 의 __MAIL_PASSWORD__, __DB_PASSWORD__ 등
# __...__ placeholder 를 실값으로 치환

    Note

    application*.yaml은 @PropertySource("classpath:application.yaml")로 직접 로드되므로(예: config/property/SecurityProperty.java:15) 실파일이 없으면 기동이 실패한다. .example만 두고 복사를 빠뜨리지 말 것.

    프로파일 (Profile)¶

    spring.profiles.active 기본값은 default다(application.yaml.example:29-30). 실행 시 -Dspring.profiles.active=dev|prod로 변경한다.

    java -jar -Dspring.profiles.active=dev vp-backend.jar
    프로파일 포트 출처 비고
    default(로컬) 9041 application-default.yaml.example:5 세션쿠키 SINOKORSESSION
    dev 8080(base 상속) application-dev.yaml.example DataSource/Redis만 override
    prod 8080(base 상속) application-prod.yaml.example DataSource/Redis만 override
    azure(ACA) 9041(명시) application-azure.yaml.example 시크릿은 컨테이너 env(KV secretRef)로 주입, 파일엔 AMR TLS/포트 10000 등 정적 설정만
    • base server.port는 8080, server.address는 0.0.0.0이다(application.yaml.example:7-8). default 프로파일이 이를 9041로 덮어쓴다.
    • 프로파일 판별 헬퍼: SpringProperty.Profiles의 isDefault()/isDev()/isProd()(config/property/SpringProperty.java:20-30).
    • 로깅 설정도 프로파일 기반으로 선택된다: logging.config=classpath:logback/logback-${logging.fileName}.xml, logging.fileName 기본값은 ${spring.profiles.active}(application.yaml.example:172-174). azure는 fileName: default로 콘솔 전용 logback을 쓴다.

    default 프로파일 전용 동작 — SQL 핫리로드

    default 프로파일에서만 WatchedSqlSessionFactoryBean이 사용되어 mapper XML 핫리로드를 지원한다. 그 외 프로파일은 일반 SqlSessionFactoryBean이다(config/database/VpDataBaseConfiguration.java:77-79).

    회사코드(corp) 추가 설정¶

    실행 인자(args[0])가 dev가 아닐 때, base + 프로파일 YAML에 더해 classpath:/corp/{arg}.yaml을 추가 로드한다(VpApplication.java:36-40).

    외부화된 비밀값 (@Value)¶

    소스에 하드코딩되던 시크릿은 @Value로 외부화되었고, 실값은 gitignore된 YAML(또는 환경변수)에만 존재한다.

    비밀값 주입 위치 키 / 환경변수
    마스터 패스워드 core/web/security/provider/LoginUserDaoAuthenticationProvider.java:29 환경변수 MASTER_PASSWORD
    EIR/SIPG snko client-secret/password eir/service/EirService.java:67,69 eir.snko.client-secret, eir.snko.password
    EIR/SIPG halk client-secret/password eir/service/EirService.java:71,73 eir.halk.client-secret, eir.halk.password
    EIR/SIPG 요청 서명 SALT (선사별) eir/service/EirService.java:77,79 eir.snko.salt, eir.halk.salt
    ulogitech FTP(IntegrationFlow) config/integration/ftp/FtpFlowConfiguration.java:29 ftp.flow.password
    ulogitech 메일 발송 계정(IntegrationFlow) config/integration/mail/MailFlowConfiguration.java:23,26 mail.flow.username, mail.flow.password 
    // LoginUserDaoAuthenticationProvider.java:28-30
@Value("${MASTER_PASSWORD:}")
private String masterPassword;

    MASTER_PASSWORD 미설정 = 마스터 로그인 비활성

    기본값이 빈 문자열(${MASTER_PASSWORD:})이라 환경변수를 안 주면 마스터 로그인이 동작하지 않는다. 인증 분기에서 masterPassword가 비어있지 않을 때만 비교한다(LoginUserDaoAuthenticationProvider.java:68).

    Azure Monitor 대시보드(CmsAzureLog) 설정 — 비밀 아님

    azure.monitor.{subscription-id,resource-group,backend-app,law-workspace-id} 4키는 시크릿이 아니며, Azure 배포에서 env(AZURE_MONITOR_*, bicep staticEnv)로 주입된다. 인증은 azure-identity UAMI(env AZURE_CLIENT_ID). 로컬 미설정 시 대시보드 조회만 "미구성" 응답이고 기동엔 영향 없다(@Value 기본 빈값, application.yaml.example:200-208).

    YAML 내 placeholder 시크릿¶

    *.example에는 다음 비밀값들이 __PLACEHOLDER__로 들어있다(괄호는 base 기준 라인).

    • spring.mail.password → __MAIL_PASSWORD__(application.yaml.example:41)
    • spring.cloud.aws.credentials.{access-key,secret-key} → __AWS_ACCESS_KEY__/__AWS_SECRET_KEY__(application.yaml.example:69-70)
    • security.jwt-hmac256-secret → __JWT_HMAC256_SECRET__(application.yaml.example:84)
    • webpush.private-key → __WEBPUSH_PRIVATE_KEY__(application.yaml.example:144)
    • cloud.aws.credentials.{accessKey,secretKey} → __AWS_*__(커스텀 AwsS3Property용, application.yaml.example:122-123)
    • eir.snko.*, eir.halk.* → __EIR_*__(application.yaml.example) — client-secret·password·salt
    • ftp.flow.password → __FTP_FLOW_PASSWORD__(application.yaml.example:222)
    • mail.flow.{username,password} → __MAIL_FLOW_USERNAME__/__MAIL_FLOW_PASSWORD__(application.yaml.example:227-228)
    • 프로파일 파일: datasource.vp.password → __DB_PASSWORD__, ftp.pw → __FTP_PASSWORD__(application-default.yaml.example:19,27)

    @ConfigurationProperties 클래스¶

    설정은 대부분 config/property/ 패키지의 @ConfigurationProperties + @PropertySource("classpath:application.yaml") 클래스로 바인딩된다(@Data @Component, Lombok).

    클래스 prefix 주요 필드
    VpDataBaseProperty datasource.vp url, driverClassName, username, password, maximumPoolSize, minIdle
    VpMybatisProperty mybatis.vp resourcesPath, configPath, paramCount
    SecurityProperty security jwtHmac256Secret, requestPermitAllMappings(Permit[]), loginUrl, logoutUrl, username, password
    ProjectProperty project site
    SpringProperty spring profiles.active(+ isDefault/isDev/isProd)
    StompProperty websocket.stomp server.{endpoint, allowedOrigins, *DestinationPrefix}
    StorageProperty storage location, awsS3Location, prevLocation
    AwsS3Property cloud.aws credentials.{accessKey,secretKey}, s3.bucket, region(@Value)
    WebPushProperty webpush publicKey, privateKey
    MailProperty spring.mail master
    FtpProperty ftp ip, port, id, pw, uploadPath, signaturePath

    미사용 EDI 설정 계층(Edi*Property 4종과 edi.* 키)은 전면 제거되어 더 이상 존재하지 않는다.

    두 개의 AWS 설정 블록

    spring.cloud.aws.*(awspring 3.x S3Client 자동구성)와 cloud.aws.*(커스텀 AwsS3Property가 직접 읽음)가 공존한다. SB3 마이그레이션 시 자동구성용 prefix가 추가됐고 기존 커스텀 prefix는 유지됐다(application.yaml.example:65-74,118-127).

    필수 인프라¶

    공개 문서 — 호스트 마스킹

    이 사이트는 공개 레포로 발행되므로 실제 호스트/IP는 DEV-DB-HOST·MAIL-HOST 등 placeholder로 가렸다. 실값은 비공개 백엔드 레포의 application*.yaml에 있다.

    인프라 키 값(예시) 출처
    Oracle datasource.vp.url jdbc:oracle:thin:@DEV-DB-HOST:9889:skr(default) / PROD-DB-HOST:9889:skr(dev·prod) application-default.yaml.example:17, application-dev.yaml.example:5
    Redis(세션) spring.data.redis.{host,port} 전 프로파일 localhost:6379(무인증 로컬 Docker) — Azure는 SPRING_DATA_REDIS_* env override(AMR, 포트 10000/TLS) application.yaml.example:56-57, application-dev.yaml.example:15-16
    AWS S3 cloud.aws.s3.bucket, region.static pilos2-file-server, ap-northeast-2 application.yaml.example:125-127
    메일 spring.mail.{host,port} MAIL-HOST:465(SSL) application.yaml.example:39,42
    업로드 FTP ftp.ip FTP-HOST:21(default/dev/prod) application-default.yaml.example:24-26
    • 세션은 Redis 저장(spring.session.store-type: redis), 타임아웃 7200초/쿠키명 SINOKORSESSION(application.yaml.example:59-63, application-default.yaml.example:9).
    • 인증/세션: JWT는 HMAC256(security.jwt-hmac256-secret). 공개(permit-all) URL은 Java config가 아니라 security.request-permit-all-mappings에 method/urls로 선언한다(application.yaml.example:85-108).
